# RPA事例・志望動機の編集記録

出典：2026-09-05の本人の説明。仮説検証事例は本人の意向により後日追記する。

## RPA：本人確認済み
- 対象は、基幹システムに落とし込めない低リードタイム製品の工程管理。
- 本人がRPAをローコード開発ツールとして使い、Excel作業からデータ管理まで含むツールを実装。
- 管理者の手動Excel運用の工数を約4時間／日削減。
- 22時まで一人で残業する状態から、17時定時で退社する変化があった。
- 教育・利用者の自立はうまくいかなかった。ローコードでもプログラミングの本質は残り、適性や時間制約によって自立した開発が成り立たない場合があるという本人の結論。

## 数値と表現
約4時間／日は本人把握の概算。測定方法・対象期間は未確認。22時から17時への変化と同一指標にせず、5時間削減へ換算しない。全社員への効果、年間費用換算、現在も同じ効果が継続するという推測は加えない。
利用者の能力を一律に断定せず、適性・時間等の条件によって自立が難しい場合があるという学びとして記す。

## 志望動機
AIの可能性を現場に届けることを使命のように感じ、AIで減らせる負担が届いていないことが「どうしても気になる」という内発的な動機を中心に編集。
DigeonでのAI開発と精和工業所での業務支援の双方の体験、自身もAIとの会話方式に馴染めない感覚、導入の仕方による抵抗感への懸念、行政への関心、求人をXで見て行動したことを反映。
第三者の認識・発言、人類全体のAI利用に関する断定は、根拠のない外部事実として掲載しない。本人の体験と考えとして記す。具体的な政策支持や党への所属は推測しない。
