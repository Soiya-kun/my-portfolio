# ヒアリング
回答は `npm run private:init` で作成する `.private/intake.md` に記入する。このテンプレートには個人情報を記入しない。

## 最初に聞きたいこと
- 公開する氏名・表示名・肩書き
- 経歴：期間、組織（匿名可）、役割、担当範囲、技術、公開可否
- 代表事例2〜3件：現場の課題／発見方法／自分の判断／実装／結果／学び
- 個人の貢献とチームの貢献の区別
- 応募理由と、政策・広聴の現場で取り組みたいこと
- 応募目標日、制作に使える時間

## 次に確認すること
- 成果の根拠：測定期間、比較条件、測定方法。数字がなければ観察できた変化
- 失敗・仮説の修正・運用改善・非エンジニアとの協働
- 生成AIを使った仕事と品質確認の方法
- 公開できるGitHub・記事・登壇・デモ・資格のURL
- 会社名、顧客名、画面、コード、数値それぞれの掲載許諾
- 顔写真・メール・SNS・職務経歴書の公開範囲
- デザインの好み、参考サイト、英語版の要否
- AWSリージョン、ドメイン、月額予算（認証情報は書かない）
- 募集条件との対応：実務年数、スタートアップ経験、出社中心の勤務など

## 事例記入欄（必要な数だけ複製）
- 仮タイトル／期間／役割／チーム規模：
- 課題と発見方法：
- 制約と検討した選択肢：
- 自分の判断と実装：
- 検証・結果・根拠：
- 失敗と改善：
- 公開可の内容：
- 匿名化が必要／要確認／非公開の内容：
