## 本人確認済みの事実と手法
- 約300万円規模では、一人で顧客折衝から開発まで完了。
- 約2億円規模では、PMとして技術面の責任を担い、顧客との合意形成に重心が移った。
- アジャイル的な進め方を多く採っていたが、ウォーターフォール型の契約を前提とした説明・筋道が不足し、合意形成に失敗。
- 次の案件から、プレキックオフで相手方PMとキックオフ後のスタートに事前合意する進め方を採用。
- 合意の対象は「AsIsの全量」と「それらを確認するセッションをどのペースで組めるか」の2点。
- 合意を基準に、時間不足や日程を組めないことなどの差分を管理する手法を確立した。
- 未把握事項が存在する可能性も前提に含め、双方が現時点で決められる範囲をすべて、AsIs全量とセッションスケジュールという管理可能な形にする。
